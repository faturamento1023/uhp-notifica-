# Ícones do UHP Notifica

PNGs individuais com transparência e recorte justo, exportados de uma base de 96 × 96 px. Use na interface em uma caixa de 20 a 24 px com `object-fit: contain`.

```html
<img src="/icons/pdf.png" alt="" width="24" height="24" style="object-fit:contain">
<span>Gerar PDF para o setor</span>
```

Para botões que mostram apenas o ícone, informe o nome da ação no `aria-label` do botão. Mantenha o texto para ações e estados que precisem de identificação explícita.
